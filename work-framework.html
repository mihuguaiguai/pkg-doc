👥 相关方分工

  • IE / SC — 提前知晓到货信息
  • 收货员（手动） — 核对文件/实物/查询系统/识别异常
  • 收货员（SAP） — 打印PO/SAP录入/标识管理/缺陷报告
  • QA / SC — 异常通知、判定处置、不合格处理
  • 采购 — 确认PO/协调供应商补件/异常沟通
  • QC compliance — 法规审查

🔑 三单一致核对要素

  • 物料编码（Material Code）
  • 物料名称（Material Description）
  • 批号（Batch Number）
  • 生产日期 & 有效期
  • 供应商名称
  • 送货数量
  • PO 订单号
📋 填写要求：蓝色签字笔，错误处单横线更正并签名注日期，不得用涂改液

⚠ 常见异常 & 处理

  • 文件异常/破损 → 停止收货，通知 SC
  • 来货标签异常 → 停止收货，通知 SC/QA
  • 数量/重量/有效期不符 → 通知 QC/采购综合处理
  • 供应商信息不符 → 停止收货，通知 SQE
  • 送货量与PO不符 → 部分接收，通知采购确认
  • 无证书/证件 → 停止收货，通知 SC 确认
  • COA原件丢失/模糊 → 要求供应商补件

升版 SOP

文件变更申请 → 审批 → 培训 → 旧版回收 受控执行

📂 文件管理系统
🔗 打开 Mango 系统 对应 SOP：QM001 / QM002 / QM003
📌 标准流程
1. 变更需求提出
任何人发起变更申请
→
2. 起草修订
发起人（Mango 作者）在系统中起草
→
3. 部门审核
部门负责人内容审核
→
4. QA 技术审核
QA 合规性审核
→
5. QA 最终审批
授权人签批发布
→
6. 培训执行
相关人员培训 + 签到
→
7. 生效归档
旧版回收，新版生效

🔑 关键要素

  • 变更原因与变更内容明确记录
  • 版本号规则（如 V1.0 → V2.0）
  • 生效日期与培训完成日期
  • 培训签到记录存档
  • 旧版受控回收记录
  • 对应 SOP：QM001 / QM002 / QM003

⚠ 注意事项

  • 旧版文件必须全部回收，不能有残留
  • 培训未完成前不得按新版执行
  • 跨部门影响需通知所有相关部门
  • 法规变化引起的升版需评估合规影响
  • 紧急变更需走临时偏差流程
